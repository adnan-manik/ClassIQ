Abstract: Assigning teachers to class sections remains a largely manual exercise: Heads of Department rely on intuition and limited historical records, so mismatches between teaching styles and student learning preferences, along with the peer conflicts that disrupt a classroom, surface only weeks into the semester when correcting them is costly. ClassIQ addresses this by building a digital twin of a classroom, a structured profile of every student and teacher assembled before the semester begins. The platform is built with Next.js, React and Tailwind CSS on the front end, FastAPI on the back end, and PostgreSQL hosted on Supabase with row-level security for multi-tenant isolation. Students are profiled on the four Felder-Silverman (FSLSM) axes scored from the 44-item Index of Learning Styles, while peer relationships are modelled as a social graph using NetworkX. A compatibility engine combines four weighted factors, namely style alignment, social cohesion, class balance and participation mix, into a score from 0 to 100 rated High, Medium or Low, and a what-if scenario builder lets a Head of Department compare alternative section configurations side by side before applying one. Survey, RDF and CSV ingestion, role-based dashboards, early-warning flags, longitudinal analytics and an LLM-powered assistant that answers natural-language questions over institutional data complete the platform, which is intended as pre-semester decision support rather than a predictor of grades.

Keywords: Digital Twin, Learning Analytics, Felder-Silverman Learning Style Model, Compatibility Scoring, Social Network Analysis, Scenario Simulation, Decision Support System, Classroom Intelligence, Large Language Models, Multi-Tenant Web Application.
